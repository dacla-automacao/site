# Downloads

Pasta reservada para arquivos públicos do site:

- catálogos de produtos (PDF)
- manuais técnicos
- datasheets
- firmwares e imagens de cartão

Para publicar um arquivo, basta colocá-lo neste diretório e referenciá-lo na seção **Downloads** do `index.html`:

```html
<a href="downloads/nome-do-arquivo.pdf" download>Baixar PDF</a>
```
